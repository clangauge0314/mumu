# mumu

무사시노 국제기숙사 중고거래 플랫폼

## 구조

```
mumu/
├── frontend/     # React + Vite 앱
└── README.md
```

## 로컬 실행

```bash
cd frontend
npm install
npm run dev
```

`.env`는 `frontend/.env`에 두세요 (`frontend/.env.example` 참고).

## 스크립트

| 명령 | 설명 |
|------|------|
| `npm run dev` | 개발 서버 (기본 `http://localhost:5173`) |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
